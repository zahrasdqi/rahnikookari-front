# Rahnikookari Front

وب‌سایت فرانت‌اند مؤسسه خیریه راهِ نیک، توسعه‌داده‌شده با React و Vite.

## معرفی پروژه

این پروژه رابط کاربری وب‌سایت «راهِ نیک» است و با هدف ارائه‌ی یک تجربه‌ی کاربری مدرن، روان و ساختاریافته برای کاربران طراحی شده است.

## تکنولوژی‌ها

- React
- Vite
- SCSS
- React Router DOM
